# Source-backed formatter refresh

- Classified this as a compatible VS Code formatter integration fix targeting `0.8.1-alpha.1`; the latest immutable extension release is `0.8.0`.
- Build a discovered `Eidosc.Cli` source backend into an isolated output directory before formatting, preventing `--no-build` from silently using stale formatter code.
- Keep the formatter build separate from the long-lived LSP output so Windows file locks do not block formatter updates.
