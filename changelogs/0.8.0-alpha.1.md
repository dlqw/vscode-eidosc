# Eidos Language 0.8.0-alpha.1

- Updated the extension's validated language range to Eidos `>=0.8.0-alpha.1 <0.9.0` and its compiler range to Eidosc `>=0.5.0-alpha.1 <0.6.0`.
- Added lexical highlighting and compiler-backed semantic support for `then` / `else` selection payload placeholders such as `_0` and `_1`.
- Renamed the Marketplace extension to **Eidos Language** with extension id `eidos-language`.
- Added the Eidos owl mark as the Marketplace listing icon and the `.eidos` / `eidos.toml` file icon in both light and dark editor themes.
- Added prerelease Marketplace publishing to the protected release workflow, including publisher credential verification and a matching GitHub VSIX release artifact.
